# Content Pulse 2.0

Витрина съёмок поверх Яндекс Диска компании. Работает в браузере, одинаково на Windows и Mac.

- **Витрина:** список папок съёмок из архива на Диске.
- **Съёмка:** галерея прямо с Диска (превью Яндекса), отбор в карточки по шаблонам (движок Cardboard).
- **Общий отбор:** хранится в `<съёмка>/_contentpulse.json` и виден всем. Чужие правки не затираются: при конфликте подтягивается свежая версия.
- **Действия над кадром или карточкой:** на ретушь (с подстраховочной копией в `<съёмка>/Ретушь/<дата>/`), на пересъём, на согласование.
- **Скачивание:** отбор по карточкам (папка на карточку, порядок слотов в имени файла) или вся съёмка со структурой подпапок. Повторное скачивание докачивает только недостающее. Работает в Chrome и Edge.
- **Журнал:** кто, что и когда сделал.

Файлы остаются на Диске. Своего сервера нет.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | интерфейс Cardboard (вёрстка карточек, шаблоны) |
| `cp-disk.js` | клиент REST API Яндекс Диска: повторы на 429/5xx, докачка, копии, общий файл с проверкой ревизии |
| `cp-app.js` | слой Content Pulse: вход через Яндекс, витрина, сохранение на Диск, статусы, журнал, скачивание |

Настройки — в начале `cp-app.js` (`CP_CONFIG`): ClientID приложения Яндекса, путь к архиву по умолчанию.

## Проверка

```bash
node tests/e2e.js   # браузер + подменённый API Диска, 21 проверка
```

На настоящем Диске проверяется вручную: вход, витрина, открытие съёмки, ретушь, скачивание.
